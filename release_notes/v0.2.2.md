# GWexpy v0.2.2

GWexpy v0.2.2 is a maintenance release that restores GWpy-compatible default
sample selection for `TimeSeries.crop()` while retaining exact HDF5 epoch
metadata as private GWexpy state.

## Highlights

- `TimeSeries.crop()` delegates GWpy-supported bounds to GWpy, including
  high-rate boundary selection.
- Exact epoch propagation happens only after the base slice succeeds.
- Non-integral-nanosecond cadences drop derived exact authority instead of
  turning a successful GWpy slice or crop into an exception.
- Collection-first explicit I/O performs the same stable lazy registry
  bootstrap as scalar I/O.
- The release workflow qualifies one immutable wheel/sdist payload across 19
  cells before publication is permitted.

## Compatibility

Default values, selected samples, and time-axis metadata are compared directly
with GWpy 4.0.1 and 4.0.2 at 4 Hz, 4,096 Hz, 1 MHz, and 10 MHz.

This release implements the project-wide
[GWpy behavioral compatibility policy](../docs_redesign/explanation/gwpy_compatibility_policy.md).

No new exact-time opt-in argument is introduced in this release.

## Installation

```bash
pip install gwexpy==0.2.2
```
