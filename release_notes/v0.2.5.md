This patch release hardens public cross-format I/O following the #751 audit.
Characterized Zarr, NetCDF4, HDF5, TDMS, GBD, and audio routes preserve
serialized values and metadata, and invalid stores fail with clear errors.
Optional Zarr and NetCDF4 backends remain optional for base installations.

### Fixed

- Preserved integer and complex values, axis units, and matrix cell metadata in supported Zarr and NetCDF4 routes.
- Rejected malformed HDF5 collection manifests and invalid TDMS/GBD metadata.
- Preserved clear missing-backend errors for public I/O methods.
