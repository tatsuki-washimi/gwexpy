コマンドラインインターフェース（CLI、試作版）#

概要#

ステータス: 試作版（安定性ラベル）

GWexpy CLI は現在 最小限のプレースホルダ的インターフェースであり、試作段階の機能として扱ってください。現時点では、GWexpy は主に Python API を用いた対話的解析およびスクリプティングで利用することを想定しています。

現在のステータス#

GWexpy CLI は 初期開発 / 試作段階です。現在実装されているのはバージョン表示と簡単な案内メッセージが中心であり、高度な解析ワークフローは安定したサブコマンドとしてはまだ公開されていません。完成済みのユーザー向け CLI とみなす段階ではありません。

利用可能なコマンド#

gwexpy --version#

インストールされている GWexpy のバージョンを表示します：

gwexpy --version

出力（数字はインストールされているバージョンに一致します）:

gwexpy <installed version>

gwexpy --help#

一般的なヘルプ情報を表示します：

gwexpy --help

GWpy CLI の使用#

GWpy のコマンドラインツールを利用したい場合は、GWpy ドキュメントを直接参照してください。GWexpy は現在、GWpy CLI 全体を透過的に転送する互換レイヤを文書化していません。

注意: 複雑な解析パイプライン、重力波パラメータ推定、独自のデータ処理には Python API を推奨します。API の例は はじめに ガイドを参照してください。

今後の開発予定#

今後の GWexpy リリースでは、以下の専門的なサブコマンドを追加予定です：

  • データ取り込みと検証

  • ノイズ特性評価

  • 時間-周波数解析

  • イベント位置決定

予定されている機能や時期については、公開されている ロードマップ を参照してください。

トラブルシューティング#

インストール後に gwexpy コマンドが見つからない場合は、GWexpy が正しい環境にインストールされていることを確認してください：

pip install -e .

インストールを確認します：

python -c "import gwexpy; print(gwexpy.__version__)"
