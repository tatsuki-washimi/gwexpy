ケーススタディ#

複数の GWexpy 機能を組み合わせ、自分のデータに応用できる完結した実例解析にまとめた、目的志向のワークフローです。機能ごとのレッスンは、まず チュートリアル と 技法レシピ から始めてください。

注目#

ノイズバジェット

BrUCo 方式のバジェットで、対象スペクトルを実測された寄与に分解します。

ノイズバジェッティングと多チャンネル相関解析
伝達関数

コヒーレントな加振から多チャンネル伝達関数を推定しプロットします。

チュートリアル: 伝達関数の測定
アクティブ制振

6自由度防振系のための MIMO アクティブ制振ループを設計・検証します。

6自由度アクティブ防振装置のアクティブダンピング (非コロケート配置)

I. 較正・応答・制御#

  • アクティブ制振: 6自由度防振系の MIMO 制御

  • 伝達関数測定: 推定・コヒーレンス・フィッティング

  • 較正パイプライン: counts から strain への変換

  • DTT XML ワークフロー: 実測応答データの読み込みと再利用

II. 相互運用・入出力・再現性#

  • Finesse 3 相互運用: シミュレーションと実測の比較

  • ObsPy 相互運用: 地震データの取り込みと解析

  • GBD フォーマット入出力: 検出器データ生成物のラウンドトリップ

  • HDF5 来歴管理: 再現可能なメタデータ管理

  • PyCBC 相互運用: gwexpy の前処理から探索まで

III. 統計・機械学習ワークフロー#

  • ブートストラップ PSD と GLS フィッティング

  • ML 前処理パイプライン: 特徴量エンジニアリングと比較

  • イベント同期解析: SegmentTable による窓選択

  • 物理的妥当性チェック: 単位・下限・サニティテスト

  • ARIMA に基づくバースト検出

  • 信号抽出: 有色ノイズからの微弱信号復元

IV. ノイズ探索と検出器診断#

  • ノイズバジェット: 支配的なノイズカップリングの特定

  • ロックイン検出: 微弱な AM/FM 構造の復元

  • ウィーナーフィルタ: コヒーレントノイズの差し引き

  • カップリング解析: チャンネル間の伝達経路の推定

  • Bruco と ICA によるノイズ低減: ウィットネス選択から差し引きまで

  • Bruco 応用: 双線形カップリングと AM/FM の破綻モード

  • バイオリンモード解析: 共振系列のフィッティングと追跡

  • シューマン共振の解析

  • グリッチ解析: Q 変換と Omega スキャン

注釈

上の注目ケーススタディにはサムネイルを表示しています。残りのギャラリーは、CI で実行済みノートブックのサムネイルが生成されるまではリンクとして掲載します。
