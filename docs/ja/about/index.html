貢献#

GWexpy はコントリビューションを歓迎します。手短に言うと、リポジトリをフォークし、変更用のブランチを作成して、main に対してプルリクエストを開いてください。詳細なワークフロー、コーディング規約、テストの期待値については CONTRIBUTING.md を、コミュニティにおける行動指針については Code of Conduct を参照してください。

このドキュメントサイトをローカルでビルドするには、docs_redesign/ ディレクトリで sphinx-build -b html . _build/html を実行します。日本語訳は docs_redesign/locales/ 配下の gettext カタログとして提供されています。英語の原文を変更した後にカタログを更新するには、sphinx-build -b gettext . _build/gettext を実行してから sphinx-intl update -p _build/gettext -l ja を実行し、生成された .po ファイル内の新規の空エントリを翻訳してください。
