class gwexpy.fields.ScalarField(value, *, unit=None, name=None, epoch=None, channel=None, dtype=None, copy=True, subok=True, order=None, ndmin=0, axis0=None, axis1=None, axis2=None, axis3=None, axis_names=None, axis0_domain: str = 'time', space_domain: str | dict[str, str] = 'real')#

ベースクラス: FieldBase

A 4-dimensional scalar field with domain tracking.

ScalarField represents a physical field defined on a 4D grid (typically 1 time and 3 spatial dimensions). It supports domain transformations (Fourier transforms) while preserving coordinate metadata and units.

パラメータ:

  • data (array-like) -- 4-dimensional input data.

  • unit (str, ~astropy.units.Unit, optional) -- Physical unit of the field values.

  • axis0 (array-like, optional) -- Coordinate values for axis 0 (Time or Frequency).

  • axis1 (array-like, optional) -- Coordinate values for spatial axes.

  • axis2 (array-like, optional) -- Coordinate values for spatial axes.

  • axis3 (array-like, optional) -- Coordinate values for spatial axes.

  • axis_names (iterable of str, optional) -- Names for each axis (length 4).

  • axis0_domain ({'time', 'frequency'}, optional) -- Initial domain of the first axis.

  • space_domain ({'real', 'k', 'angle'} or dict, optional) -- Initial domain of the spatial axes.

  • **kwargs -- Additional keyword arguments passed to FieldBase.

メモ

A key feature of ScalarField is that slicing always returns a 4D ScalarField. Integer indices are automatically converted to length-1 slices to prevent dimension loss.

>>> from gwexpy.fields import ScalarField
>>> data = np.ones((2, 2, 2, 2))

fft_space(axes: Iterable[str] | None = None, n: Sequence[int] | None = None, overwrite: bool = False, spacing_rtol: float | None = None) → ScalarField#

Compute FFT along spatial axes.

This method uses the two-sided unnormalized forward DFT (scipy.fft.fftn) and produces angular wavenumber coordinates (k = 2π·fftfreq).

パラメータ:

  • axes (iterable of str, optional) -- Axis names to transform (e.g., ['x', 'y']). If None, transforms all spatial axes in 'real' domain.

  • n (tuple of int, optional) -- FFT lengths for each axis.

  • overwrite (bool, optional) -- If True, perform FFT in-place on a temporary copy of the data to reduce peak memory usage. Default is False.

  • spacing_rtol (float, optional) -- Opt-in dimensionless deviation tolerance for approximately uniform axes. When None (default), strict AxisDescriptor.regular and AxisDescriptor.delta are used. When provided, is_regular(max_deviation=spacing_rtol) and AxisDescriptor.mean_delta() are used, emitting a UserWarning if the axis does not pass strict regularity.

戻り値:

Transformed field with specified axes in 'k' domain. Any attached GeoMetadata is deactivated (active=False).

戻り値の型:

ScalarField

例外:

ValueError -- If any specified axis is in 'angle' domain (convert first via to_local_cartesian() or to_projected()), is not in 'real' domain, or is not uniformly spaced.

メモ

Fourier Normalization and Parseval Convention

Forward coefficients match unnormalized scipy.fft.fftn:

\[F[k] = \sum_{n=0}^{N-1} f[n] \, e^{-i 2\pi k n / N},\]

with inverse ifft_space() applying 1 / N via scipy.fft.ifftn, so Parseval's identity along transformed axes is:

\[\sum |f|^2 = \frac{1}{\prod N_j} \sum |F|^2.\]

Angular Wavenumber Convention

The wavenumber axis is computed as k = 2π * fftfreq(n, d=|dx|), satisfying k = 2π / λ with units of 1 / dx_unit.

Sign Convention for Descending Axes (dx < 0)

If the spatial axis is descending (dx < 0), the k-axis is sign-flipped to preserve physical consistency with e^{+ikx}.

Approximate Grids (``spacing_rtol``)

When spacing_rtol is given and an axis passes the relaxed G3 least-squares criterion without passing strict regularity, exact input coordinates are retained privately so ifft_space() restores them when axis length and wavenumber spacing remain unchanged.

to_local_cartesian(origin: tuple[float | Quantity, float | Quantity] | None = None, *, names: tuple[str, str] = ('x', 'y'), ellipsoid: str = 'GRS80') → ScalarField#

Convert two 'angle' spatial axes (lon, lat) to local tangent-plane metres.

Uses the local ellipsoid curvature radii at the origin latitude \(\phi_0\):

\[x = N(\phi_0) \cos(\phi_0) \, (\lambda - \lambda_0), \qquad y = M(\phi_0) \, (\phi - \phi_0),\]

where \(N(\phi_0) = a / W(\phi_0)\) is the prime-vertical radius of curvature, \(M(\phi_0) = a(1 - e^2) / W(\phi_0)^3\) is the meridional radius of curvature, and \(W(\phi_0) = \sqrt{1 - e^2 \sin^2\phi_0}\).

For approximately uniform input angle grids, output axes are resynthesized as (arange(n) - i0) * d to preserve uniform spacing; for genuinely nonuniform angle axes, exact point-by-point mapped coordinates are preserved.

メモ

This tangent-plane approximation removes first-order ellipsoid flattening bias at the origin, but parallel convergence still introduces east-west scale distortion of order \(|\tan\phi_0| \cdot (|\Delta y| / N(\phi_0)) = O(\mathrm{span}/R)\) away from origin, plus \(O((\mathrm{span}/R)^2)\) curvature effects. For wide areas or strict CRS reprojection, use to_projected().

パラメータ:

  • origin (tuple of (lon0, lat0), optional) -- Local tangent-plane origin in degrees (or angular Quantities). Defaults to the midpoint of the two angle axes.

  • names (tuple of (str, str), default ('x', 'y')) -- Output names for the converted spatial axes.

  • ellipsoid ({'GRS80', 'WGS84', 'sphere'}, default 'GRS80') -- Reference ellipsoid parameters.

戻り値:

Field with converted axes in 'real' domain with metre units. Any attached GeoMetadata is deactivated with local_origin=(lon0, lat0).

戻り値の型:

ScalarField

  • orthogonalize=True (default): constructs a right-handed orthonormal basis \((\hat{e}_x, \hat{e}_y, \hat{e}_z)\).
