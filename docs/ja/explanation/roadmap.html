ロードマップ#

このページは、GWexpy のドキュメント整備と機能計画の公開ロードマップ入口です。 厳密なリリース契約ではなく、どの方向へ改善を進めているかを共有するための概要として扱ってください。

最終更新: 2026-08-26。

このページの読み方#

  • リリース済みの基準：提供済みの v0.2.0 semantic contract

  • 方向性のあるテーマ：今後の iteration で改善する可能性がある領域

  • 中期: 現在の docs / API 整理の後で広げていきたい領域

  • 長期: 有用だが、まだ具体的な時期を固定していない方向性

ロードマップは公開していますが、研究上の要請や保守コスト、上流依存の変化によって優先度は変わりえます。

現在のリリース基準#

  • v0.2.0 は、予測可能な unit、metadata の伝播、暗黙の型 downgrade ではなく明示的な failure から成る container arithmetic の基準を確立します。

  • exact timing、相互運用可能な persistence、決定論的な provenance、公開 GWpy compatibility は v0.2.0 で提供済みです。

方向性のあるテーマ#

次の minor に committed なテーマはありません。以下は方向性のあるテーマであり、リリースの約束や予約済みの version 番号ではありません。

  • ナビゲーション、アクセシビリティ、検索性を含むドキュメント品質改善

  • GWpy ユーザー向け移行ガイドの明確化

  • notebook / tutorial の CI 上での安定性向上

  • チュートリアル、ガイド、API リファレンス間の参照強化

より長期の方向性#

  • フィールドコンテナ(正規格子のスカラー・ベクトル・テンソル場)のファイル直接読み書き。地形(標高)データや GeoTIFF を含め、単位・軸・メタデータを一貫して保持

  • セグメント単位の解析ワークフローの完結: セグメントの読み込み、選択、エラー・欠損の明示的な処理、保存、再開

  • 多数の実験セグメントの集約・要約を、手書きのループなしで行う

  • フィールド・地形データにおける物理座標系の一貫した取り扱い

  • 現在は試作段階に留まる CLI の拡張

  • ノイズ特性評価や時間周波数解析ワークフローの拡充

  • 外部の科学計算 Python ライブラリとの相互運用ガイドの拡充。データ準備ツールが書き出した HDF5 プロダクトの読み込みや、干渉計の設計・シミュレーションパッケージの出力の取り込みを含む

  • 数値アルゴリズムや物理前提に関する公開検証ノートの充実

これらの連携が周辺エコシステムとどう関係し、どのプロジェクトを意図的に対象外としているかはGW Python エコシステムにおける GWexpy の位置付けを参照してください。

  • フィールドデータの空間幾何: 座標フレーム、検出器に整合した回転、地形・物理場・サイトマーカーを重ねる地図可視化

  • メッシュ構造を保持するフィールドモデルと、数値ソルバー出力との相互運用

  • 行列コンテナ上に構築する予測・推定ユーティリティ(Fisher 解析など)

  • 下流のアプリケーションや GUI が拠り所にできる、安定して文書化された公開 API

  • 対応する実験データ形式間で、時刻の解釈（タイムゾーン、数値時刻のスケール、エポック）と読み取り処理の挙動を一貫させる

  • 事例とリファレンスを横断して探せるビジュアル・ナビゲーションの強化

  • ドキュメント検証とサンプルコード検証の自動化拡張

  • テーマ、検索品質、インタラクティブ表示の改善

補足#

このロードマップは開発方針の共有用であり、実装順序やリリース時期を保証するものではありません。 GWexpy は研究用途のソフトウェアであり、今後の状況に応じて優先度が見直される可能性があります。
