## Context

v0.2.7 は 2026-10-31 に公開された。2026-11-01 の chat2plan セッションで、ユーザーが v0.2.8 のスコープとして案 B を採用した。案 B は、科学データの単位の整合と、誤った数値結果を防ぐための保守リリースである。

- #767: PercentileThreshold は単位変換に失敗しても、警告を出したあと変換していない値を加算している（`gwexpy/analysis/threshold.py:365-380`）。
- #768: `standardize_matrix` の単位。要素単位（`meta.units`、公開プロパティ `units` から参照）は入力単位を保持している可能性がある。`TimeSeriesMatrix` にスカラー `.unit` はない。
- #769: StandardizeTransform の単位処理が壊れている。`.unit` への代入が `AttributeError` になり、それを握りつぶしている（`pipeline.py:284-287`）。`_apply_matrix` は単位に触れない。未知の `method` は黙って z-score として扱われ、scale==0 は黙って 1 に置き換えられる。multivariate=True の Collection 往復では順変換の Matrix 型と逆変換後の元 Collection 型を明示する必要がある。

加えて、リリース基盤（`scripts/ci/`、`scripts/validate_release.py`）にはタグ名が v0.2.7 までコードに直接書かれている。そのため v0.2.8 対応が必須である。対応しないと、レビュー証跡なしで検証を通る fail-open 経路も残る（F-08）。

## Goal

- #767・#768・#769 を、決定 D1〜D4 と Step 7 で承認する Phase 0 仕様に従って修正する。
- 意図した挙動の変更は CHANGELOG で開示する。
- RELEASING.md の既存の S/R・ゲート方式（v0.2.7 の前例: prep 3d968cfc5 → S defa8efda → R bcf6e0c98）で v0.2.8 を公開する。

## Target Release

- 目標公開日: **2026-11-04（水）**。この目標のために科学的検証や既存の公開承認を省略しない。
- S に含める `.zenodo.json` と `CITATION.cff` の公開日項目は原則 `2026-11-04` とし、independent date policy を維持する。日付一致は必須でないが、S 確定前に各日付と契約を確認する。
- 公開日が目標からずれる場合は、Source 固定・承認・メタデータの既存契約に従う。
