# GWexpy v0.1.13 release plan

v0.1.13 is a correctness-first, minimal stabilization release.  Work is done
in a clean worktree based on `origin/main`; the dirty primary worktree is not a
release input.

## Scope

- Merge the CI checkout hardening from #631 first.
- Deliver the fail-closed public contracts for RMS, NetCDF/Zarr/GBD selection,
  NetCDF v2 timing and dtype handling, ROOT histogram import, Field and
  Histogram arithmetic, GWF parallel arguments, NDScope writing, and vector
  plotting stride routing.
- Correct unsupported `.ffl` reader claims and remove provisional DOI and
  SoftwareX assertions from public release metadata.
- Defer #508, #513, #618, #620, FFL implementation (#625), provenance schema,
  streaming/parallel implementations, NDScope option expansion, and Histogram
  arithmetic to v0.2.0.

## Required release gates

Every implementation lane receives an independent Terra review.  A Sol
integration review then checks the API contract, I/O boundaries, backwards
compatibility, package artifacts, and release metadata.  Required checks are
Ruff, MyPy, tests, EN/JA documentation builds, package build, strict twine,
metadata validation, and clean Python 3.11/3.12 wheel installation.

The release remains NO-GO until the exact crop/PSD invariant, dedicated I/O
gates, metadata/DOI consistency, PyPI trusted publisher, Zenodo integration,
Sol approval, and explicit human GO all exist.  Publishing, tagging, PyPI,
GitHub Release, and Zenodo operations are human-only and are not performed by
this implementation branch.
