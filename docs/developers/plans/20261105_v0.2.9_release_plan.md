# GWexpy v0.2.9 Release Plan

Status: source preparation. Issue [#871](https://github.com/tatsuki-washimi/gwexpy/issues/871) records the Release Owner's fixed product scope and is the designated Release Owner GO record. It does not approve a source, grant GO, authorize a tag, or authorize publication.

## Scope

The adopted product changes are limited to these four fixes:

- #770: align `TimeSeriesMatrix.radian()` and `.degree()` values with container and per-element units.
- #774: reject malformed or dimensionally incompatible, nonempty HDF5 `frequency_unit` metadata while preserving valid frequency-unit conversion and the absent-attribute fallback.
- #778: restore fit-time physical units in `WhitenTransform.inverse_transform()` without changing whitening calculations.
- #866: restore detector-channel and GPS-plot proxy imports on GWpy 4.1.0 and retain 4.0.x compatibility.

Issue #771 and the broader scientific-data-integrity work are deferred to v0.2.10. Issue #865 is separate. The v0.2.9 scope does not add public APIs, dependencies, or persistence schemas.
