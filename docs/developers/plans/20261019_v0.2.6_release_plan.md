This file is the active release plan for v0.2.6.

## Candidate scope and maintenance release definition

v0.2.6 is a maintenance release that provides focused diagnostic and documentation improvements and cleans up the repository configuration, documentation, tests, and CI boundaries following the decoupling of the legacy in-tree GUI to the independent `pyaggui` repository (#645).

It introduces no new public APIs, dependencies, or storage formats. Tested scientific values, dtypes, axes, and units are preserved.

### In-Scope Work Included

1. **ASD frequency-grid rejection diagnostics (#790, PR #794)**: Distinguish frequency-grid rejection causes when validating response functions, preserving warning categories and stack levels.
2. **`TimeSeries.spectrogram2()` documentation (#779, PR #798)**: Clarify non-averaged periodogram execution path and argument constraints.
3. **`TimeSeriesDict.append()` documentation (#640, PR #798)**: Clarify in-place update behavior and `self` return contract.
4. **Legacy in-tree GUI cleanup (#645, PR #802, PR #803)**:
   - Complete removal of `gwexpy/gui/` and `tests/gui/`.
   - Complete removal of GUI-specific development dependencies (`pytest-qt`, `pytest-xvfb`) and packaging discovery exceptions.
   - User guides and how-to guides updated to direct users to `pyaggui` and `GWexpy Studio`.
   - Adoption of [ADR 0001](../adr/0001-gui-decoupling-and-project-boundaries.md).
   - Implementation of automated CI hygiene and boundary defense tests (`scripts/check_repo_hygiene.py`, `tests/test_gui_boundary.py`).

### Deferred Issues with Technical Rationale

The following open high-impact issues identified during error audits were investigated and are explicitly deferred from the v0.2.6 maintenance release (deferrals are accepted known risks/limitations for v0.2.6 and do not automatically constitute confirmed inclusions for v0.3.0):

- **#766 (framel segmentation fault on missing file)**: DEFERRED. Native crash occurs in third-party C library (`framel` `frgetvect`) when reaching missing files via GWpy single-source read with both `backend='framel'` and `backend=None`. Changing path validation or exception semantics in GWexpy would alter standard GWpy-parity I/O behavior; deferred to upstream/dedicated I/O contract cycle.
- **#767 (`PercentileThreshold.threshold()` unit-mismatch raw evaluation)**: DEFERRED. GWexpy-specific analysis helper. Emits a `UserWarning` while continuing raw array evaluation when units mismatch, without guaranteeing physical validity of the returned threshold. Establishing a strict rejection or safe conversion policy requires an explicit design decision for analysis pipelines.
- **#768 (`standardize_matrix` retaining input units)**: DEFERRED. GWexpy multidimensional container helper. Retains `.units` and per-element units despite producing dimensionless z-scores. Mutating container metadata in-place requires coordinated verification across downstream matrix operations.
- **#769 (`StandardizeTransform` pipeline unit residue & fallback)**: DEFERRED. GWexpy pipeline transform. Retains fitted unit residues; unsupported method silently falls back to z-score. Requires API contract review for Pipeline estimators.
- **#770 (`TimeSeriesMatrix.radian`/`degree` units mismatch)**: DEFERRED. GWexpy matrix container operation. Leaves `.units` and element `.unit` at source physical units while top-level metadata indicates radians/degrees. Requires multi-axis metadata synchronization design.
- **#771 (Non-manifest HDF5 collection silent drop on read failure)**: DEFERRED. Collection readers catch per-element read failures and skip them. Clarifying tolerant non-manifest read contracts and error policies requires container-wide consensus.
- **#773 (`to_tgraph` error-bar unit compatibility)**: DEFERRED. ROOT interoperability helper. Helper array extraction does not verify error-bar unit compatibility with series units. Requires full ROOT integration testing and specification of error-bar unit relations.
- **#774 (`frequency_unit` invalid attribute fallback to Hz)**: DEFERRED. Interop HDF5 reader falls back to Hz for unrecognized frequency units. Defining an explicit failure or alias mapping contract requires broader I/O format review.
- **#777 (`SeriesMatrix.to_hdf5` dropping Quantity attributes)**: DEFERRED. HDF5 JSON metadata serialization drops Quantity-valued custom attributes without warning. Requires extending metadata serialization schema for complex objects.
- **#778 (`WhitenTransform.inverse_transform` physical unit restoration)**: DEFERRED. Pipeline transform fails to restore original physical units on inverse transform. Requires coordinated Pipeline unit-tracking design.
- **#784 (`python -m gwexpy.time` entrypoint ImportError)**: DEFERRED. Caused by GWpy 4.x CLI refactoring. Formal CLI entrypoint contract to be re-evaluated in next feature cycle.
- **#765-C2 (`local_hurst` algorithm implementation)**: DEFERRED. Independent follow-up to parent audit #765.
