## Candidate scope and maintenance release definition

v0.2.6 is a maintenance release that provides focused diagnostic and documentation improvements and cleans up the repository configuration, documentation, tests, and CI boundaries following the decoupling of the legacy in-tree GUI to the independent `pyaggui` repository (#645).

It introduces no new public APIs, dependencies, or storage formats. Tested scientific values, dtypes, axes, and units are preserved.

### In-Scope Work Included

1. **ASD frequency-grid rejection diagnostics (#790, PR #794)**: Distinguish frequency-grid rejection causes when validating response functions, preserving warning categories and stack levels.
2. **`TimeSeries.spectrogram2()` documentation (#779, PR #798)**: Clarify non-averaged periodogram execution path and argument constraints.
3. **`TimeSeriesDict.append()` documentation (#640, PR #798)**: Clarify in-place update behavior and `self` return contract.
4. **Legacy in-tree GUI cleanup (#645, PR #802, PR #803)**:
   - Complete removal of `gwexpy/gui/` and `tests/gui/`.
   - Complete removal of GUI-specific development dependencies (`pytest-qt`, `pytest-xvfb`) and packaging discovery exceptions.
   - User guides and how-to guides updated to direct users to `pyaggui` and `GWexpy Studio`.
   - Adoption of [ADR 0001](../adr/0001-gui-decoupling-and-project-boundaries.md).
   - Implementation of automated CI hygiene and boundary defense tests (`scripts/check_repo_hygiene.py`, `tests/test_gui_boundary.py`).
5. **Obsolete NDS live workflow retirement (Release Owner decision, #797)**: Remove `.github/workflows/nds-live.yml`, whose `pytest -m nds tests/` selector has no remaining marked tests after the GUI cleanup. Update developer testing guidance and add a regression test. Retain NDS-related library I/O and offline analysis support; no replacement live-NDS workflow is promised or required.

### Accepted Known Limitations and Deferred Issues

The Release Owner accepted deferral of the ten issues below for v0.2.6 in the decision recorded on [tracking issue #797](https://github.com/tatsuki-washimi/gwexpy/issues/797#issuecomment-6264255764). They remain unresolved known limitations and are individual patch candidates for v0.2.7 or later; this does not promise that any issue will be fixed in v0.2.7. Public impact and issue links are recorded in `release_notes/v0.2.6.md` and `CHANGELOG.md`. No unverified workaround is advertised.

- **#766 (framel segmentation fault on missing file)**: DEFERRED. A missing GWF path passed to the native `framel` read route (`backend='framel'` or `backend=None`) can terminate the process with a segmentation fault. No safe workaround is verified.
- **#767 (`PercentileThreshold.threshold()` unit-mismatch raw evaluation)**: DEFERRED. Incompatible PSD units reaching `bkg_table` can be followed by raw-magnitude threshold evaluation after a warning, so the result may lack a valid physical interpretation. No safe workaround is verified.
- **#768 (`standardize_matrix` retaining input units)**: DEFERRED. The matrix and elements can retain source units after producing dimensionless z-scores, which can mislead unit-aware downstream operations. No workaround is verified.
- **#769 (`StandardizeTransform` pipeline unit residue & fallback)**: DEFERRED. Standardized values can retain physical-unit metadata and an unrecognized method can silently fall back to z-score. No workaround is verified.
- **#770 (`TimeSeriesMatrix.radian`/`degree` units mismatch)**: DEFERRED. Converted values can have container and element units that remain inconsistent with the angular values, which can mislead unit inspection. No workaround is verified.
- **#771 (Non-manifest HDF5 collection silent drop on read failure)**: DEFERRED. Some collection readers can silently skip entries that fail to read and return partial or empty data. A successful return does not guarantee every stored entry was loaded. No workaround is verified.
- **#773 (`to_tgraph` error-bar unit compatibility)**: DEFERRED. Error-bar quantities with units incompatible with the series can be accepted without a compatibility check, potentially misrepresenting uncertainties. No workaround is verified.
- **#774 (`frequency_unit` invalid attribute fallback to Hz)**: DEFERRED. An invalid nonempty HDF5 `frequency_unit` attribute can be interpreted as Hz without warning, potentially mislabeling the frequency axis. No workaround is verified.
- **#777 (`SeriesMatrix.to_hdf5` dropping Quantity attributes)**: DEFERRED. Quantity-valued custom attributes can be omitted from HDF5 output without warning, losing metadata on round-trip. No workaround is verified.
- **#778 (`WhitenTransform.inverse_transform` physical unit restoration)**: DEFERRED. The inverse transform can return dimensionless data without restoring the original physical units. No workaround is verified.

The other issues and audit follow-ups not listed above remain outside this ten-item decision; this plan does not reclassify or close them.
