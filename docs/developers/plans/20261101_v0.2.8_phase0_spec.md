## 単位と戻り値の契約

`StandardizeTransform` は、fit 時に値の統計量に加えて、Matrix 化する前の元 Collection の型、Dict key または List の順序、および各元系列の `.unit` を保存する。

`multivariate=False` の Dict と List は入力と同じ collection 型で順変換し、逆変換でも同じ型を返す。

`multivariate=True` の Dict と List は順変換で `TimeSeriesMatrix` を返す。逆変換はその Matrix を入力に取り、fit 時に保存した構造と単位を使って元の Dict または List に戻す。

Dict の逆変換では元の key を保ち、List の逆変換では元の順序を保つ。

未知の Dict key と List 要素に対する既存の挙動を保つ。

未知 key は順変換で現行どおり処理し、逆変換では既存の `KeyError` または `IndexError` を送出する。

| 入力経路 | 順変換の戻り値と単位 | 逆変換の戻り値と単位 |
|---|---|---|
| `TimeSeries` | `TimeSeries`。`.unit` は dimensionless | `TimeSeries`。fit 時の値と `.unit` を復元 |
| `TimeSeriesMatrix` | `TimeSeriesMatrix`。`.units` と `meta.units` の全要素が dimensionless | `TimeSeriesMatrix`。fit 時の値と要素単位を復元 |
| Dict、`multivariate=False` | 同じ Dict 型。各系列の `.unit` が dimensionless | 同じ Dict 型。元の key、値、単位を復元 |
| List、`multivariate=False` | 同じ List 型。各系列の `.unit` が dimensionless | 同じ List 型。元の順序、値、単位を復元 |
| Dict、`multivariate=True` | `TimeSeriesMatrix`。`.units` と `meta.units` の全要素が dimensionless | 元の Dict 型。fit 時の key、値、単位を復元 |
| List、`multivariate=True` | `TimeSeriesMatrix`。`.units` と `meta.units` の全要素が dimensionless | 元の List 型。fit 時の順序、値、単位を復元 |

`multivariate=True` の Matrix 出力と元 Collection への逆変換は D3 の戻り値契約である。Matrix 化により元系列の単位や Dict key が失われないよう、fit 時に Collection の復元情報を保持する。`multivariate=False` の戻り値型は既存どおりとする。

`standardize_matrix` は入力を変更せず、出力の `meta.units` と参照用公開プロパティ `units` の各要素を dimensionless にする。単位変更は要素ごとの `meta.units` setter を通し、スカラー `.unit` を読み書きしない。

`standardize_matrix` は単位以外の既存 metadata を保ち、整数 dtype の入力でも要素 metadata を失わない。

z-score の受入数値は、明示した `ddof` に対する平均およそ0、標準偏差およそ1とする。

robust の受入数値は、中央値およそ0と、採用した MAD scale の定義に対する scale およそ1とする。

GW strain 程度の振幅（標準偏差およそ `1e-21`）をゼロ scale と判定しない。

## R-016：axis ごとの単位プール契約

`standardize_matrix` と `StandardizeTransform` の実装は独立させたまま、`axis="channel"` で複数チャネルを同じ統計母集団として扱う場合は、各チャネルの値を先頭チャネルの単位へ換算してから平均・標準偏差または中央値・MADを計算する。単位が物理的に非互換なら `ValueError` を送出する。共通単位選択に新しい公開 API や引数を追加しない。

例えば `1 m` と `200 cm` を pool する場合、統計対象は `[1, 2] m` であり、`ddof=0` の z-score は `[-1, +1]` となる。換算前の数値 `[1, 200]` を同じ母集団として処理しない。

`axis="time"` では各チャネルを独立に標準化する。チャネル間で単位が非互換でも拒否せず、各チャネルの自身の単位を使って計算し、出力を dimensionless とする。

`StandardizeTransform` の `inverse_transform` は fit 時に保存した各元系列の単位、数値、チャネル順序、時刻情報およびその他の既存 metadata を復元する。単位換算を経た `1 m` と `200 cm` は、それぞれ元の数値と単位に戻す。

## R-017：StandardizeTransform の退化時方針

この方針は #769 の `StandardizeTransform` にのみ適用する。#768 の `standardize_matrix` は、R-016 の単位換算を適用しつつ、既存の数値的退化時動作を維持する。

| 条件 | `StandardizeTransform` の動作 |
|---|---|
| 有限の定数チャネル | 有限値の max と min の厳密比較で判定し、中心化後のゼロを返して `UserWarning` を発行する |
| 非定数チャネルで MAD=0 | `ValueError` |
| scale が NaN または Inf | `ValueError` |
| 標準偏差が約 `1e-21` など、極めて小さい非ゼロ値 | 通常どおり標準化する。絶対値ベースの一律閾値を設けない |

NaN は既存の保持契約に従う。逆変換などの既存契約に必要な場合に限り fit 時の退化フラグを保存し、用途のない状態管理は追加しない。

## #767 の単位変換動作

`bkg_table` の各背景行を入力 PSD の単位へ変換できる場合は、換算した値を従来どおり加算する。

行の単位変換に失敗した場合は `UnitConversionError` を送出し、変換前の値を加算しない。

失敗を警告だけで済ませる経路を残さない。

回帰テストは、非互換な PSD 単位、後続行だけが非互換となるケース、PSD と ASD の混在、互換単位の正しい換算を確認する。

`CouplingFunctionAnalysis` の現行呼び出し元は `AttributeError` だけを捕捉するため、D2 の `UnitConversionError` は解析呼び出し元まで伝播する。

Coupling への伝播は D2 から導かれる挙動として CHANGELOG と回帰テストに記録する。

旧来の `raw_bkg` 経路に単位検査を加える R-019 は不採用であり、今回の変更対象に含めない。
