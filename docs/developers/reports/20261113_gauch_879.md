The product statistic map also matches these original statistics at rtol=1e-12,

The original driver is not launched as a cluster CLI. Its actual AST statements at

## Production-statistic null comparison

The experiment uses 20,000 independent time-series windows to generate each FFT
null and another 20,000 independent windows to evaluate it. It uses the actual
product ASD and KS helpers, checks their result against `compute_gauch()` on a
complete first window, and uses the product rank-p-value helper. The independent
amplitude null uses the product generators with scale refitted in every trial.

Settings match the earlier standalone benchmark: 256 Hz, 1 s Hann FFT, constant
detrending; no overlap/n=40 and 50% overlap/n=39. These calibration experiments
are distinct from the 4096 Hz original-function comparison above. They do not
claim exhaustive calibration over all sample rates or FFT lengths.

| Overlap | Bin class | Independent-null P(p<=.05) | FFT-null P(p<=.05) | Independent-null P(p<=.01) | FFT-null P(p<=.01) |
|---|---|---:|---:|---:|---:|
| 0% | Interior pooled | .052560 | .049832 | .010361 | .010005 |
| 0% | DC | .046050 | .049450 | .008700 | .009750 |
| 0% | Nyquist | .047550 | .048000 | .010000 | .011200 |
| 50% | Interior pooled | .050914 | .049665 | .010459 | .009910 |
| 50% | DC | .052700 | .051400 | .011800 | .010850 |
| 50% | Nyquist | .047650 | .055300 | .010900 | .013150 |

The JSON retains first/second interior bins separately, per-group rates and their
mean/median/SD/SE. Evaluation windows are split into 40 independent groups of 500;
frequency bins within a window are not treated as independent observations for
those errors. The paired group SE conditions on the generated null and **does not
include its common Monte Carlo error**.

Four disjoint 5,000-trial null blocks provide a rough separate null-error estimate
(block-rate SD / sqrt(4)); this is a diagnostic with only four blocks, not a
precision guarantee. At 50% Nyquist the independent-minus-FFT rate difference is
-0.00765, paired evaluation SE 0.000675, and separate null SE estimates are
0.000805 (independent) and 0.002158 (FFT). The difference must not be judged using
the evaluation SE alone. Correlation and finite-null variation both remain
possible contributors; these results do not establish equivalence.

**Scientific decision requested:** assess this bin-specific comparison and its
uncertainty before accepting the independent amplitude null. If materially
inaccurate, prefer a scoped overlap-aware calibration under #879. No such null
redesign or automatic scientific approval is introduced by this evidence update.

### Odd-length final bin reproduced in the product

The new experiment ran `compute_gauch()` from this checkout (`PYTHONPATH=.`)
with `nfft=33`, a 39-ASD-sample window, disjoint FFT segments, 4,000 independent
evaluation windows and 20,000 simulated null statistics (seed 20261113). The
first interior bin was the control. Under the previously selected fitted-
Rayleigh null, the odd final bin rejected 17.65% at nominal alpha=.05 (binomial
SE .00603) and 7.80% at alpha=.01. The control rejected 4.975% at alpha=.05.
The review's formula-level NumPy result is therefore reproduced through the
production API; this is new product-path evidence, not the saved earlier
standalone calculation.

The narrow repair retains the observed fitted-Rayleigh KS statistic, but
generates its reference distribution from the matching Gaussian FFT process.
For a mean-removed, Hann-windowed bin the coefficient kernel is
`w[j] exp(-2πikj/nfft) - mean(w exp(-2πikj/nfft))`. Covariances between segments
are dot products of shifted kernels over shared time samples. The Monte Carlo
draws from the resulting multivariate Gaussian coefficient distribution, then
uses the same fitted KS statistic and `(r+1)/(N+1)` rank p-value. This models
both the odd-final-bin real/imaginary variance ratio and any accepted 50% overlap
without changing the public API or the statistic. The deterministic coefficient
test confirms `Var(Im)/Var(Re)=5` for the tested odd final bin and checks the
covariance matrix against the direct demeaned, windowed coefficient vectors.

With the matched process null, the same evaluation windows rejected 5.60% at
alpha=.05 (evaluation SE .00364) and 1.225% at alpha=.01. Four independent 5,000-
trial null blocks give a rough shared-null SE estimate of .00240. The .05 rate
is consistent with nominal size once both evaluation and null Monte Carlo error
are considered; the old Rayleigh result is not. The production-path regression
also checks the odd final-bin rejection rate on an independent seeded dataset.

### 50% overlap DC/Nyquist decision

The prior report's common-null uncertainty was considered explicitly. In the
saved 20,000-evaluation comparison, the 50%-overlap Nyquist difference was
.00765, but the paired evaluation SE alone omitted the shared-null error. Four
5,000-trial blocks estimated null SEs of .00081 for the independent-amplitude
null and .00216 for the FFT-process null. Their combined uncertainty is
approximately .0023, so that old run did not establish a stable difference.

A new product-helper experiment used 20,000 independent time-domain windows,
20,000 trials per null, 40 groups, 256-sample Hann FFTs, a 128-sample hop and
seed family 20261213–20261223. Each evaluation statistic was checked against
`compute_gauch()` for the first complete window. Results at alpha=.05:

| Bin | Independent-amplitude null | FFT-process null | Paired evaluation SE | Independent / FFT null-block SE |
|---|---:|---:|---:|---:|
| DC | 5.195% | 4.800% | .00047 | .00147 / .00129 |
| Nyquist | 5.115% | 5.225% | .00020 | .00136 / .00154 |

Both nulls are consistent with nominal 5% after accounting for their shared
null estimation error. The DC difference is about two combined block standard
errors, but both individual rejection rates lie within one combined error of
5%; the Nyquist rates agree within the estimated error. The prior Nyquist
discrepancy is not reproduced. No DC or even-FFT Nyquist production change is
justified by these results, so their independent half-normal null and existing
behavior remain unchanged.

### KAGRA compatibility, guard, and verification status

The committed #900 KAGRA results remain the accepted reference: ASD maximum
absolute error 0; fitted-scale peak-relative errors `2.80e-16` and `2.78e-16`;
two-sided KS maximum absolute error `3.33e-16`; and zero operational threshold

both KAGRA FFT lengths (4096 and 24576 samples) are even, and its comparison
band excludes Nyquist. The added even-FFT overlap test verifies the unchanged
DC/Nyquist half-normal p-value path. This source-level scope and the committed
numerical record support compatibility, while a direct rerun still requires
the original supplied files.

The explicit `nfft=3` `ValueError` guard is unchanged. The saved 5,000-window
diagnostics found ungated nominal-.05 rejection rates .3016, .3252 and .3314
for hops 1, 2 and 3. Analytically, for a three-sample periodic Hann and the
single positive-frequency bin after mean removal,
`Var(Im X)/Var(Re X)=9`; Rayleigh magnitudes require equal real and imaginary
variances. Since the failure also occurs with disjoint segments, it cannot be
explained by overlap dependence. Keeping the guard avoids applying the
interior-bin Rayleigh null where its premise fails.
