# B-F3 DTTXML baseline-v1

This append-only directory freezes the B0 published v0.2.4 and B1 old-R v0.2.5 wheel behavior for issue #589. The installed B1 wheel is the public oracle. All six modes use the exact `benchmarks/io/*.py` bytes identified by the directory digest; later harness edits require a separate checkout of this freeze commit for candidate comparisons.

The deterministic helper generated 27 cases in independently regenerated small, warmup, and large roots. Every case file SHA-256 and all non-path manifest fields matched between the two roots. XML source files are regenerated from `benchmarks/io/f3_dttxml_fixtures.py`; the manifest records each source path, byte count, and SHA-256. The large valid PSD has one selected 16,384-point series and 256 unselected series in a 22,577,909-byte XML file.

B0 and B1 public correctness fingerprints agree across all 27 cases and native, external, and forced optional-package-absent fallback routes. The raw records preserve ordered keys, sample and axis hashes, units, epochs, warning categories/messages, logger records, error type/message/cause, and actual parser route. Independent fixture oracles check selected PSD values/frequencies and TF/6 complex phase/frequency identity. `channels=None` returns source-order channels; `channels=[]` returns an empty public dict on both arms. With dttxml 1.1.8 installed, public TS ignores `native=True` and uses the external route; only the forced fallback reaches the native TS parser.

The #589 exception is confined to warnings and decode errors from fully unselected native payloads. The baseline separately captures selected/unselected PSD payload faults, metadata faults, late XML syntax overriding earlier payload faults, TS warnings, and structural identity errors. Native TF/6 unselected nonfinite frequency, FFT unselected invalid length/nonreal frequency, and STF unselected invalid length raise semantic `ValueError`s. Those product selection optimizations are HOLD; the runtime claim is restricted to the eligible public native PSD path. External behavior is an independent unchanged contract. The full warnings and exact errors are in the raw public samples.

Separate large structural runs show 16,777,216 decoded bytes for fully unselected PSD streams in each B0/B1 sample. Unselected `FrequencySeries` construction is already zero, so it is not a performance claim. Five samples per arm use ABBA interleaving for structural, warm, cold, and Linux process-tree PSS/RSS modes. Warm timing uses one process per arm with a warm-up then function-level repeats; cold starts a fresh process per sample. Full wheel byte audits and fixture hashes run outside the timed parser call. The Linux 5 ms sampler reports an estimated peak, not a guaranteed instantaneous maximum. PSS reduction and zero unselected decode bytes are co-primary gates; wall is supporting.

Both arms use wheel-only `--no-deps --no-index` installs into matched Python 3.12.12 `--system-site-packages` venvs and `python -I` workers. The B0 wheel is the published PyPI artifact. The B1 wheel's 369 package members were byte-compared to clean old-R source at `1eb2cd62`; the frozen C1 provenance manifest is referenced below. All installed wheel members are audited before each mode. The manifests include wheel hashes, dependency versions, import paths, raw samples, medians, MADs, and SHA-256 for every evidence file.
