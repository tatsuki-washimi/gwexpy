# SDB candidate v3 evidence (HOLD)

This append-only package records the exact source and wheel measurement for commit `221d3fce7349b35b26b0a50614d42a5790a7ea5f`. Candidate v3 is on HOLD following independent review findings about fresh GWpy crop boundary semantics, empty-window epoch preservation, and non-finite selectors.

`evidence-manifest.json` identifies the candidate and baseline wheels, frozen harnesses and fixtures, 14-case WAL matrix, static source parity, INT64 overflow parity, DataFrame materialization structure gate, warm/cold measurements, and supporting PSS samples. `artifact-sha256.json` hashes every other file in this directory. SDB-only inputs needed for reproducibility are under `fixtures/`; WAL mutations are generated by the frozen harness from its base database.

The structural result counts only rows materialized into the pandas payload DataFrame (4096 for B1, 512 for v3). Candidate validation still scans the full source in O(N). No wall-time, full-scan-elimination, or PSS improvement claim is made. The documented broad concurrent-WAL exception remains subject to S2 scientific/data-model approval and scoped disclosure.
