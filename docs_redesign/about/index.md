# About

GWexpy extends [GWpy](https://gwpy.github.io/) with multi-dimensional
containers and the analysis methods that operate over them. It is aimed at
gravitational-wave detector characterisation and related multi-channel,
multi-dimensional time-series work.

## Project

- **Source** — <https://github.com/tatsuki-washimi/gwexpy>
- **License** — see the repository
- **Built on** — GWpy, NumPy, SciPy, and the wider PyData stack

## Citing

If GWexpy contributes to your research, please cite the project. Citation
metadata is provided in the repository.
