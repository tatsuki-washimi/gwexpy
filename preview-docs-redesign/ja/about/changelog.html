更新履歴 (Changelog)#

GWexpy の主な変更履歴を記載します。

[0.1.5] - 2026-06-10#

プロットと I/O の修正を中心としたパッチリリースです。

修正 (Fixed)#

  • TimeSeriesDict.plot() を修正し、複数チャンネルの辞書が空白または不正な図になる問題を解消して、チャンネルごとのサブプロットに展開されるようにしました（#432）。

  • ObsPy ベースの地震計データリーダーを修正し、TimeSeriesDict のキーが安定した文字列トレース名（例: "IU.ANMO.00.BHZ"）となり、文字列での確実な参照ができるようになりました（#435）。

  • TimeSeriesDict.read(..., format="mseed") に miniSEED パスのリスト/タプルを渡せるようになりました（#433）。

  • gwexpy.frequencyseries のインポート時 I/O 登録を修正し、FrequencySeries の読み込みフォーマットが GWpy 標準の I/O レジストリから見えるようになりました（#437）。

ドキュメント (Documentation)#

  • GWexpy は GWpy の上に構築された独立パッケージであり、GWpy プロジェクトの公式コンポーネントではないことを明確化しました。

  • README のインストール注記を更新し、conda-forge feedstock が利用可能である一方、conda-forge パッケージは最新の PyPI リリースより遅れる場合があることを反映しました。

[0.1.4] - 2026-05-14#

追加 (Added)#

  • to_gps() にオプトインの dtype= 出力モードを追加しました。既定は GWpy 互換のままで、dtype=float / dtype="float" は素の数値秒を返し、dtype="quantity" は .times と直接比較できる秒の quantity を返します。

ドキュメント (Documentation)#

  • README、ドキュメントのハブページ、ロードマップ、トラブルシューティングページ、フッターのリンクが、軽微なバグ報告と機能要望を公開フィードバックフォームへ案内するようになりました。セキュリティ報告は引き続きリポジトリのセキュリティポリシーに向けられます。

テスト (Tests)#

  • 明示的な時間座標を要求する NetCDF フィクスチャのカバレッジを追加しました（#393）。

  • マルチチャンネルのリストソース読み込みと、parallel > 1 でのパディングされたギャップ読み込みについて、GWF の回帰テストカバレッジを追加しました。

[0.1.3] - 2026-05-12#

修正 (Fixed)#

  • TimeSeries および TimeSeriesDict 入力に対する複数ファイル GWF 読み込みを修正しました。

  • TimeSeriesMatrix.read() における ndscope HDF5 の自動検出を修正しました。

  • 公開 I/O ドキュメントと契約メタデータを、現在の自動検出の挙動に合わせました。

  • FrequencySeries の CSV 高速パスで、元の周波数列の値を保持するようにしました。

  • zarr 3 の行列往復変換カバレッジを改善し、タイムアウトしやすいフィクスチャの挙動を除去しました。

  • 読み込み可能な GMT 共有ライブラリを持たない PyGMT インストールを、インポート時に失敗させるのではなく、利用不可のオプションバックエンドとして扱うようにしました。

既知の問題 (Known Issues)#

  • 同梱の一部 NetCDF フィクスチャパスは、TimeSeries リーダーの時間座標契約に失敗することがあります（#393）。生成された NetCDF 往復変換カバレッジは引き続き通過します。ファイルは明示的な時間座標を公開すべきです。

[0.1.2] - 2026-05-08#

対象を絞った hotfix 範囲#

  • GWpy4 向け公開 I/O proxy import と GWF list/dict read 挙動の互換性修正。

  • histogram HDF5、ATS/MTH5、audio、seismic、SegmentTable span CSV、FrequencySeries DTT XML の auto-identify/read-path 修正。

  • この統合トラックでは #369 の最小 landing/demo import hunk のみを含みます。

[0.1.1] - 2026-04-28#

追加 (Added)#

  • SegmentTable、histogram/segments 補助機能、detector/time 変換、CLI、plot helper に関する公開契約の基準化ドキュメントとテストを追加。

  • PyPI 公開前の release gate として、メタデータ整合性、配布物の健全性、fresh environment での wheel smoke を確認する仕組みを追加。

変更 (Changed)#

  • optional extras、ソースインストール、将来の配布チャネル切り替えに関する案内を整理。

既知の制限とフォローアップ (Known Limitations And Follow-Ups)#

  • #293 の最終段階である PyPI 公開はまだ人手実行のままです。公開インストール手順は、最初の PyPI リリースと post-publish smoke が成功するまで GitHub / ソース導入のままにします。pip install gwexpy への切り替えは公開後に行います。

  • conda-forge パッケージはまだ公開されていません。#294 では staged-recipes 提出と fresh conda 環境での smoke test を継続します。

  • ノイズ契約（#278）、astro range の単位と前提（#282）、BruCo/coupling/response ワークフロー（#284）、preprocessing / decomposition / forecasting 契約（#288）は、現状挙動の docs/test baseline は入ったものの、方針決定が残っています。

  • GUI と可視化まわりでは、payload metadata、ラベル、colorbar、plot helper の意味論、公開ドキュメントの残差 drift が継続課題です（#274、#275、#283）。GUI は引き続き安定性ラベル上の実験的機能です。

  • ローカル検証のフォローアップ #335 では、pytest tests/ -q を 1 プロセスで通したときに exit 139 が断続的に発生します。分割スイートでは通過していますが、単一プロセス異常終了の原因は未解明です。

[0.1.0] - 2026-04-08#

追加 (Added)#

  • ドキュメントデザインの刷新 (Task 1 & 2)。

  • SeriesMatrix 系クラスの安定化。

  • ScalarField による多次元データサポートの強化。

修正 (Fixed)#

  • CITATION.cff の追加による引用の容易化。

  • 依存関係の整理とOS別インストールガイドの充実。

過去の履歴#

詳細は GitHub Releases を参照してください。
